# Exercicios - Formulários HTML

### Exercício 1: Formulário de Login Simples

Crie uma página HTML com um formulário de login. Este formulário deve conter:

1.  Um **campo de texto** para o nome de usuário ou e-mail.
2.  Um **campo de senha** para a senha.
3.  Um **botão de envio** para submeter o formulário.
4.  Certifique-se de que os campos tenham os rótulos (`<label>`) adequados para acessibilidade.

**Dica:** Use `<input type="text">` e `<input type="password">`.

---

### Exercício 2: Formulário de Pesquisa de Mercado

Crie um formulário para coletar informações sobre hobbies e preferências de uma pessoa. Inclua os seguintes elementos:

1.  Um **campo de texto** para o nome completo.
2.  Um **campo de e-mail**.
3.  Um grupo de **botões de rádio** para que o usuário escolha seu nível de experiência com programação (Iniciante, Intermediário, Avançado).
4.  Um grupo de **caixas de seleção** (`checkboxes`) para que ele selecione seus hobbies (Ex: "Leitura", "Esportes", "Música").
5.  Uma **área de texto** (`<textarea>`) para o usuário deixar um comentário.
6.  Um **botão de envio**.

**Dica:** Lembre-se que os botões de rádio devem ter o mesmo atributo `name` para que a seleção seja exclusiva.

---

### Exercício 3: Formulário de Cadastro Completo

Agora, crie um formulário de cadastro mais detalhado, incluindo diferentes tipos de campos:

1.  Um **campo de texto** para o nome.
2.  Um **campo de e-mail** com o atributo `required`.
3.  Uma **lista de seleção** (`<select>`) para o usuário escolher o país. Adicione pelo menos três países na lista (`<option>`).
4.  Um **campo numérico** (`<input type="number">`) para a idade.
5.  Um **campo de data** (`<input type="date">`) para a data de nascimento.
6.  Um **botão de envio**.

**Dica:** Este exercício exige que você use diferentes tipos de `input`. Para a lista de países, você precisará das tags `<select>` e `<option>`.
